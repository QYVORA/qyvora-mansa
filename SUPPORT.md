# Support

Mansa is an open-source QYVORA product. Free community support is
available; there is no paid tier required.

## Getting help

- **Bugs & feature requests**: open a GitHub issue.
- **Questions**: use the GitHub Discussions tab or open an issue.
- **Security issues**: follow [SECURITY.md](SECURITY.md) — do not post
  vulnerabilities publicly.

## When filing an issue

Include:

- `mansa version`
- OS and Go version
- The command you ran
- The full error output
- Whether it reproduces in `--sim` mode

## Scope of support

Community maintainers respond on a best-effort basis. There is no
guaranteed response time or SLA.

## Authorized use

Remember: Mansa is for assessing networks you own or are authorized to
evaluate. Review [SECURITY.md](SECURITY.md) and
[docs/authorization.md](docs/authorization.md).
